키워드 검색량

네이버 검색수를 보려면 내 검색광고 API 키가 필요합니다. 무료이고, 광고비 없이 5분이면 받을 수 있습니다.

  1. 아래 버튼으로 네이버 검색광고에 로그인합니다. 처음이면 광고주로 가입합니다.
  2. 화면 오른쪽 위 PC 버전(또는 데스크톱 사이트)으로 바꾼 뒤 광고시스템에 들어갑니다.
  3. 도구 → API 사용 관리에서 API 서비스 신청을 누릅니다.
  4. 나오는 액세스라이선스, 비밀키(‘보기’를 눌러 전체), CUSTOMER_ID를 복사해 아래에 붙여넣습니다.

검색수 조회 준비가 끝났습니다. 블로그 포화도와 트렌드 그래프까지 쓰려면 네이버 개발자센터 키를 하나 더 넣습니다. 나중에 [설정]에서 해도 됩니다.

  1. 아래 버튼으로 개발자센터에 로그인 → 애플리케이션 등록.
  2. 이름은 아무거나, 사용 API에 검색과 데이터랩(검색어트렌드)을 추가합니다.
  3. 환경은 WEB 설정, URL은 http://localhost를 넣고 등록합니다.
  4. Client ID와 Client Secret을 붙여넣습니다.

최근 조회

키워드 카드를 누르면 클릭수·클릭률·블로그 문서 수가 펼쳐집니다. 길게 누르면 여러 개를 골라 트렌드로 비교할 수 있습니다.

같은 뜻의 키워드는 쉼표로 묶으면 합쳐서 봅니다 (예: 캠핑의자, 캠핑 체어).
